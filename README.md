# Quiz Quest

A quick-fire trivia game that runs in your browser. No installation or external dependencies required.

## Play

Open `index.html` in any modern web browser, then select **Let's play**.

## How to play

- Answer 10 multiple-choice questions.
- Each question has a 15-second timer.
- Correct answers earn points, with extra points for quick answers and consecutive correct answers.
- The results screen shows your score, accuracy, and best streak. Select **Play again** for another round.
- Use the music-note button to turn sound effects on or off.

## Files

- `index.html` — game interface, styles, questions, and game logic.
